# Two-Stage-Extreme-Value-Periodic-Regression-Approach

This repository contains the code and data associated with the manuscript *"Modeling Directional Seasonal Wind Speed Extremes Using a Two-Stage Extreme Value Periodic Regression Approach."*

### Contents

- **Data**: Wind speed and wind direction measurements from the CESAR (Cabauw Experimental Site for Atmospheric Research) observatory, used in the application section of the paper.
- **Functions**: R functions implementing the proposed two-stage Harmonic GPD method, along with the benchmark one-stage methods (Tensor GPD, Additive GPD) used for comparison.
- **Simulation study script**: R script used to run the simulation study, including data generation from the extended generalized Pareto distribution (EGPD) and evaluation of all three methods.
- **Application script**: R script used to fit the proposed method and benchmark methods to the CESAR data and reproduce the application results and figures presented in the paper.
